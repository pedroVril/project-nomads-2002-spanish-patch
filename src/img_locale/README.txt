==================================================
  TRADUCCION AL ESPANOL - PROJECT NOMADS (2002)
  Guia rapida de instalacion
==================================================

Esta carpeta contiene las imagenes traducidas del juego
y el archivo instalar_traduccion.bat que las copia al juego.


COMO INSTALAR
-------------
1. Haz doble clic en el archivo:  instalar_traduccion.bat
2. Si Windows te pide permiso, pulsa "Si" (es necesario
   porque el juego esta en Program Files).
3. Espera a que termine. Veras el resumen:
       Archivos copiados: 451
       Errores: 0
4. Abre el juego y listo.

NOTA: el instalador reemplaza las imagenes originales
(en ingles). Para volver a tener el juego en ingles,
restaura los archivos de la carpeta "subtitle" desde una
copia, o reinstala el juego.


SI EL JUEGO ESTA EN OTRA CARPETA
--------------------------------
Ejecuta el instalador desde una terminal pasandole la ruta
a la carpeta "book" del juego:

    instalar_traduccion.bat "D:\Juegos\Project Nomads\Run\book"

O abre el archivo con un editor de texto y cambia la linea:

    set "GAME_BOOK=C:\Program Files (x86)\Project Nomads\Run\book"

por la ruta de tu instalacion.
